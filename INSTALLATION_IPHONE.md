# Installation auf dem iPhone (Safari)

Voraussetzung: Die App ist unter einer HTTPS-Adresse bereitgestellt (`DEPLOYMENT_HTTPS.md`).

1. Adresse in **Safari** öffnen (nicht in der Vorschau einer anderen App).
2. Unten auf **Teilen** tippen (Quadrat mit Pfeil nach oben).
3. **Zum Home-Bildschirm** wählen. Namen „Krypto“ ggf. anpassen. Wenn angezeigt: **Als Web-App öffnen** eingeschaltet lassen. **Hinzufügen** tippen.
4. App **über das neue Symbol auf dem Home-Bildschirm** starten (nicht über Safari).
5. Einmal **mit Internet** geöffnet lassen, bis oben „Datenstand: 25.10.2026 …“ steht. Erst dann ist der Offline-Stand gespeichert.

Hinweise
* iOS bietet keinen automatischen Installationsdialog – deshalb zeigt die App auf dem iPhone keinen „Installieren“-Knopf, sondern einmalig einen Hinweis und die Anleitung unter „Info & Installation“.
* Die Home-Bildschirm-App kann einen **eigenen Speicher** haben, getrennt von Safari: Einstellungen aus Safari erscheinen dort nicht; die App muss dort einmal online geöffnet werden.
* **Keine Synchronisation** mit dem Windows-PC: Coin-/Filterauswahl wird nur auf diesem iPhone gespeichert.
* iOS kann Website-Speicher bei Platzmangel löschen. Dann einmal online öffnen.
* Update: erscheint oben „Neue App-Version verfügbar“, auf **Jetzt aktualisieren** tippen. Der Datenstand ändert sich dadurch nicht.
* Löschen: Symbol lange drücken → **App entfernen** → **Vom Home-Bildschirm entfernen**/löschen. Lokale Einstellungen können dabei verloren gehen.
