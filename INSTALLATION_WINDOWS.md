# Installation unter Windows (Edge oder Chrome)

Voraussetzung: HTTPS-Adresse (`DEPLOYMENT_HTTPS.md`). Menünamen können je nach Browserversion leicht abweichen.

## Microsoft Edge
1. Adresse in Edge öffnen.
2. Auf das **Installationssymbol** rechts in der Adressleiste klicken – oder **⋯ → Apps → Diese Website als App installieren**. (Erscheint in der App oben der Knopf **App installieren**, funktioniert auch er.)
3. **Installieren** bestätigen. Edge fragt meist, ob an **Start**, **Taskleiste** oder **Desktop** angeheftet werden soll.
4. Die App öffnet sich in einem **eigenen, frei skalierbaren Fenster** (Größe ziehen, maximieren, kleinste Breite nutzbar).

## Google Chrome
1. Adresse in Chrome öffnen.
2. **Installationssymbol** in der Adressleiste – oder **⋮ → Speichern und teilen → Seite als App installieren**.
3. **Installieren** bestätigen; je nach Version Verknüpfungen für Desktop/Taskleiste anhaken.

## Anheften
* Taskleiste: App starten → Rechtsklick auf das Symbol in der Taskleiste → **An Taskleiste anheften**.
* Start: Startmenü → App suchen → Rechtsklick → **An „Start“ anheften**.
* Sprungliste (Rechtsklick auf das Taskleistensymbol): Einträge **Marktdaten** und **Nachrichten** (App-Verknüpfungen), soweit der Browser sie anzeigt.

## Bedienung
Maus und Tastatur: Tab/Umschalt+Tab wechselt durch Filter, Bereiche und Links; Enter/Leertaste schaltet Filter; Esc schließt den Info-Dialog. Bei schmalem Fenster (< 1000 px) wechselt die Tabelle automatisch zu Coin-Karten.

## Offline, Updates, Synchronisation
* Einmal online starten, bis der Datenstand oben steht; danach ist die App offline lesbar.
* **Neue App-Version**: Hinweis „Jetzt aktualisieren“ klicken. Der Datenstand bleibt unverändert, weil der Bericht ein Archiv ist.
* **Keine Synchronisation** zwischen Windows und iPhone: jede Installation speichert ihre Auswahl selbst.

## Deinstallieren
App-Fenster öffnen → Menü (⋯ bzw. ⋮) → **App deinstallieren** (Edge: auch `edge://apps`; Chrome: `chrome://apps`). Alternativ *Einstellungen → Apps → Installierte Apps*. Der Browser kann fragen, ob auch Daten gelöscht werden sollen; lokale Einstellungen und Offline-Speicher sind danach weg, eine Neuinstallation startet sauber.
