      App installieren

      iPhone (Safari)
      1. Diese Seite in Safari öffnen (nicht in einer anderen App-Vorschau).
      2. Unten auf Teilen tippen (Quadrat mit Pfeil nach oben).
      3. Zum Home-Bildschirm wählen und mit Hinzufügen bestätigen. Falls angeboten, „Als Web-App öffnen“ eingeschaltet lassen.
      4. Die App ab jetzt über das neue Symbol auf dem Home-Bildschirm starten und dort einmal mit Internet öffnen, damit der Offline-Speicher gefüllt wird.

      iOS bietet keinen automatischen Installationsdialog; deshalb gibt es auf dem iPhone keinen „Installieren“-Knopf. Die Home-Bildschirm-App kann einen eigenen Speicher haben, getrennt von Safari.

      Windows – Microsoft Edge
      1. Seite in Edge öffnen.
      2. Installationssymbol rechts in der Adressleiste anklicken oder Menü (⋯) → Apps → Diese Website als App installieren. (Alternativ hier den Knopf „App installieren“ oben, falls sichtbar.)
      3. Mit Installieren bestätigen. Edge fragt meist, ob die App an Start, Taskleiste oder den Desktop angeheftet werden soll.
      4. Nachträglich anheften: App starten, in der Taskleiste Rechtsklick auf das App-Symbol → An Taskleiste anheften; im Startmenü Rechtsklick → An „Start“ anheften.
      Windows – Google Chrome
      1. Seite in Chrome öffnen.
      2. Installationssymbol rechts in der Adressleiste anklicken oder Menü (⋮) → Speichern und teilen → Seite als App installieren. (Alternativ hier den Knopf „App installieren“ oben, falls sichtbar.)
      3. Mit Installieren bestätigen. Je nach Version bietet Chrome Verknüpfungen für Desktop oder Taskleiste an.
      4. Nachträglich anheften: Rechtsklick auf das App-Symbol in der Taskleiste → An Taskleiste anheften, oder im Startmenü → An „Start“ anheften.
      Andere Browser

      Firefox unter Windows installiert keine Web-Apps; dort bleibt es bei der Nutzung im Browser-Tab. Safari am Mac: Ablage → Zum Dock hinzufügen. Menünamen können je nach Version abweichen.

      Deinstallieren

      iPhone: Symbol lange drücken → App entfernen. Windows: App-Fenster öffnen → Menü (⋯ oder ⋮) → App deinstallieren; oder Einstellungen → Apps → Installierte Apps. Dabei können lokale Einstellungen und der Offline-Speicher gelöscht werden (ggf. fragt der Browser danach). Eine Neuinstallation startet sauber; zuvor gespeicherte Einstellungen sind dann möglicherweise weg.

      Lokale Einstellungen

      Einstellungen (Coin-/Kategorie-Auswahl, zuletzt geöffneter Bereich, Nachrichtenfilter) werden nur in diesem Browser bzw. dieser installierten App auf diesem Gerät gespeichert. Es gibt keine automatische Synchronisation zwischen iPhone und Windows – jede Installation hat ihren eigenen Speicher. Das System kann Browser-Speicher bei Platzmangel löschen.
